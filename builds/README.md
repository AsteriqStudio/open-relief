# Android pitch APK

Download the four-tab APK and checksum from the [RC3 demo prerelease](https://github.com/AsteriqStudio/open-relief/releases/tag/phase11-demo-rc3), or run `bash scripts/build-demo-apk.sh` from the repository root with Android SDK and JDK 17 installed. The script creates `builds/open-relief-demo.apk` and its SHA-256 checksum. RC3 is an offline, fictional walkthrough of giving, recipient intake, review, and activity. It embeds the JavaScript bundle and does not require Metro or an API server. Its Android package is `org.openrelief.app`, version 0.3.0 (code 3). The generated native project and binary are ignored by Git. The release APK uses a demo debug signing key and is for sideloaded demonstrations only. See [PITCH_WALKTHROUGH.md](../PITCH_WALKTHROUGH.md).
